# FixAtHome

## Overview
FixAtHome is a web application designed to simplify home repair services by connecting users with trusted technicians. The platform allows users to book various repair services directly from their homes, ensuring convenience and reliability.

## Project Structure
```
fix-at-home
├── index.html        # Main HTML document for the website
├── style.css         # Styles for the website
├── index.js          # JavaScript functionality for interactivity
├── assets
│   └── fonts         # Directory containing font files
└── README.md         # Documentation for the project
```

## Features
- User-friendly interface for booking home repair services.
- Selection of various services including AC Repair, TV Repair, and more.
- Responsive design for optimal viewing on different devices.
- Dynamic booking list that updates as users make bookings.

## Setup Instructions
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd fix-at-home
   ```
3. Open `index.html` in your web browser to view the application.
